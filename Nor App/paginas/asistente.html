🤖 Hola, soy tu asistente NorApp

Estoy aquí para ayudarte a utilizar las principales funciones de NorApp.

Puedes pedirme ayuda con tus medicamentos, salud, ubicación, familia o una situación de emergencia.

👋 Selecciona una opción para comenzar.

💬 ¿En qué puedo ayudarte?

Selecciona una opción. No necesitas navegar por varias pantallas.

🎙️ Navegación por voz

Una de las funciones futuras de NorApp permitirá utilizar la voz para acceder a las diferentes funciones.

⌚ Preparado para el dispositivo

El objetivo es que el adulto mayor pueda decir qué necesita, por ejemplo:

🗣️ "Necesito ver mis medicamentos"

🗣️ "Quiero pedir ayuda"

🗣️ "¿Cómo está mi salud?"

Esta función podrá conectarse posteriormente con el Arduino y el dispositivo portátil.

💡 ¿Qué puede hacer el asistente?

💊 Recordatorios

Puede recordar cuándo corresponde tomar un medicamento y registrar la confirmación.

❤️ Salud

Puede mostrar la información registrada en el sistema.

📍 Ubicación

Puede mostrar la ubicación disponible para facilitar el seguimiento.

👨‍👩‍👧 Familia

Permite iniciar una acción para contactar al familiar registrado.

🆘 Ayuda

Puede iniciar el protocolo de ayuda cuando la persona indica que necesita asistencia.

🔄 ¿Cómo funciona?

1. 🗣️ La persona solicita ayuda

Selecciona una función o, posteriormente, utiliza la voz.

2. 🤖 NorApp identifica la acción

El sistema reconoce qué función necesita utilizar.

3. 💬 El asistente responde

La aplicación entrega información o inicia la función correspondiente.

4. 📋 Se registra la actividad

Cuando corresponde, la acción queda registrada en el historial.
