🔄 ¿Cómo funcionaría?

1. 📍 Registro

El sistema registra la ubicación del adulto mayor mediante el dispositivo correspondiente.

2. 👨‍👩‍👧 Consulta

La persona autorizada puede consultar la ubicación registrada.

3. 🚨 Emergencia

Si se registra una emergencia, la ubicación puede asociarse al evento.

4. 🛡️ Seguridad

La información puede ayudar a localizar al adulto mayor durante una situación de riesgo.
